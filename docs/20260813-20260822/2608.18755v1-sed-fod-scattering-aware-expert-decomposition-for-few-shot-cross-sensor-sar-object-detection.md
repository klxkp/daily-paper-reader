## 摘要
合成孔径雷达（SAR）目标检测是遥感解译的重要组成部分。然而，由于频段、分辨率、背景杂波和目标散射响应的变化，当训练和测试数据来自不同SAR域时，现有检测器的性能往往会下降。尽管域适应方法为解决该问题提供了有前景的范式，但大多数方法主要追求域不变特征对齐，并抑制对目标检测有用的传感器相关散射特征。在少样本场景中，该问题变得更加具有挑战性，因为只有少量完全标注的目标域SAR图像可用。为解决此问题，我们提出了一种散射感知的共享-特定特征分解框架，用于少样本SAR域适应目标检测。我们将检测特征分解为共享路径和几个软门控的散射特定专家路径。共享路径学习可迁移的物体结构信息，并用于非对称域对齐，而散射特定专家则自适应地补偿异构SAR响应。此外，引入了路由域辅助损失以鼓励特定专家捕获传感器相关的路由偏好，并使用专家平衡损失来防止路由崩溃。在FARAD-X/FARAD-Ka和MiniSAR之间的四个双向异构SAR检测任务上，在不同少样本设置下进行了广泛实验，实验结果表明，所提方法在前向和反向适应方向上都取得了优越的性能。

## Abstract
Synthetic aperture radar (SAR) object detection is an important part of remote sensing interpretation. However, because of variations in frequency band, resolution, background clutter, and target scattering responses, the performance of existing detectors often degrades when training and testing data are acquired from different SAR domains. Although domain adaptation methods offer a promising paradigm for solving this problem, most of them mainly pursue domain-invariant feature alignment and suppress sensor-dependent scattering characteristics that are useful for object detection. This problem becomes more challenging in few-shot scenarios, where only a few fully annotated target-domain SAR images are available. To address this issue, we propose a scattering-aware shared-specific feature decomposition framework for few-shot SAR domain adaptation object detection. We decompose detection features into a shared path and several soft-gated scattering-specific expert paths. The shared path learns transferable object structural information and is used for asymmetric domain alignment, while the scattering-specific experts adaptively compensate heterogeneous SAR responses. In addition, routing-domain auxiliary loss is introduced to encourage specific experts to capture sensor-dependent routing preferences, and an expert balancing loss is used to prevent routing collapse. Extensive experiments on four bidirectional heterogeneous SAR detection tasks between FARAD-X/FARAD-Ka and MiniSAR under different few-shot settings have been conducted and experimental results demonstrate that the proposed method achieves superior performance in both forward and reverse adaptation directions.

- **研究背景**：SAR 因全天时、全天候成像能力而广泛用于遥感解译中的目标检测任务。基于深度学习的检测器在同类成像条件下表现优异，但**跨传感器应用时性能严重下降**。
- **问题根源**：不同 SAR 传感器在**频段、分辨率、成像几何、极化方式、背景环境**等方面存在显著差异，导致目标散射特征和特征分布产生明显偏移。同一车辆目标在不同传感器下可能呈现截然不同的散射签名。
- **现有方法的不足**：
  - 传统域适应方法追求**域不变特征对齐**，将传感器相关的散射特征视为"干扰"加以抑制——但这些散射中心、阴影响应、分辨率相关结构恰恰是目标检测的有用线索。
  - 直接强制整个特征表示域不变会带来双重风险：**抑制有用散射特征导致漏检**；同时将源域的类散射背景响应强行拉向目标域，**产生虚警**。
  - 在少样本场景下（仅 K 张目标域标注图像），目标分布估计极不可靠，过度对齐更容易导致**过拟合和负迁移**。
- **核心论点**：跨传感器 SAR 域偏移不能简单视为光学域适应中的低层外观变化（如光照、雾霾等），而应区分**可迁移的目标结构信息**与**仍具判别价值的传感器相关散射信息**，两者应分别处理而非一概对齐或压制。
- **本文回答的问题**：如何在少样本跨传感器 SAR 检测中，既对齐可迁移结构，又保留并利用散射特定的判别信息？

## 2. 方法论：散射感知共享-特定特征分解框架

### 2.1 核心思想

将检测特征分解为两条互补通路：
- **共享路径（Shared Path）**：始终启用，学习跨传感器稳定的目标结构信息（形状、空间布局、目标-背景关系），用于源域选择与非对称域对齐。
- **散射特定专家路径（Scattering-Specific Expert Paths）**：多个通过软门控（soft-gated）路由加权的专家，自适应补偿频段、分辨率、杂波、阴影、散射中心分布等异构 SAR 响应。

### 2.2 关键技术细节

1. **特征分解结构**（以第 l 层特征图 F_l 为例）：
   - 共享表示：`F_sh_l = G_sh_l(F_l)`
   - 第 e 个专家表示：`F_sp_l,e = G_sp_l,e(F_l)`
   - 每个变换 G(·) 采用相同轻量结构：两次 1×1 点卷积（通道扩展比 r=2）+ GroupNorm + SiLU 激活，参数各自独立，确保专家差异来自学习到的参数与路由权重而非手工结构。

2. **软门控专家补偿**：
   - 路由器通过 `r_l = softmax(R_l(GAP(F_l)) / τ)` 预测各专家权重（τ 为温度参数）。
   - 散射特定补偿特征：`F_sp_l = Σ r_l,e · F_sp_l,e`。
   - 最终输出：`F̃_l = F_l + α_l · F_sh_l + β_l · F_sp_l`（保留残差连接，α_l 可学习、初始化 0.3，β_l 固定为 1）。
   - **关键设计**：共享路径不参与专家竞争，强制所有样本经过，避免少样本下完全依赖路由专家而过拟合。

3. **路由域辅助损失 L_rd**：将选定层的路由权重拼接后送入域分类器，预测样本域标签。该损失**不是**为了让整个表示域不变，而是鼓励路由器根据传感器相关响应模式软调整专家权重，训练后分类器移除。

4. **共享表示引导的域适应**：
   - 在共享特征空间提取源/目标图像的全局池化表示 z，用 K 个目标样本估计目标域共享表示均值 z̄_t。
   - **目标引导源选择**：基于 MMD 距离衡量源图像与目标域的相似度，优先选择相似源样本。
   - **非对称对齐**：以有限目标样本为锚点，仅对共享表示施加非对称对齐损失，避免过度对齐散射特定信息。

5. **专家平衡损失 L_bal**：约束 mini-batch 内各专家平均路由概率均匀（`L_bal = Σ ||r̄_l − (1/E)·1||²`），防止路由崩溃（少数专家支配）。

6. **总体优化目标**：`L = L_det + λ_align·L_sh_align + λ_rd·L_rd + λ_bal·L_bal`，检测损失采用 YOLOv5 的 box/obj/cls 三项损失。

## 6. 主要结论与发现

1. **总体有效性**：所提方法在 20 组评估设置中的 **19 组取得最优性能**；相比 AsyFOD†，在四个任务上的平均 mAP50 分别提升 **3.02、5.16、2.86、2.87 个百分点**（FARAD-X→MiniSAR、FARAD-Ka→MiniSAR、MiniSAR→FARAD-X、MiniSAR→FARAD-Ka）。
2. **共享与专家特征互补**：仅用共享路径或仅用专家路径均无法稳定达到完整模型效果；两者结合才能兼顾可迁移结构与散射特定补偿。
3. **对齐范围是关键**：对融合特征直接施加对齐损失会降低性能（低于完整模型），证实"仅在共享表示上对齐"的设计是有效的。
4. **路由域损失与平衡损失的贡献**：二者缺一不可——前者帮助专家学习传感器相关响应模式，后者防止少数专家主导路由，尤其对 1-shot FARAD-Ka 设置影响显著。
5. **专家数量的非单调效应**：E=2 与 E=4 性能相当且优于 E=1，但 E=8 会引入冗余路由不确定性、性能不再提升。
6. **1-shot 极限场景的敏感性**：在 MiniSAR → FARAD-Ka 的 1-shot 设置下，本文方法（23.94%）低于 AsyFOD†（26.26%），说明当源域和目标域样本都极度有限时，单个目标图像不足以可靠估计目标分布。

## 7. 方法亮点

- **问题洞察深刻**：明确指出 SAR 域偏移与光学域偏移的本质区别——散射特定信息不是"噪声"而是"判别线索"，打破了"全特征域不变对齐"的固有思路。
- **新颖的共享-特定分解范式**：将"何时对齐"与"何时保留"通过显式的特征分解来解决，思路简洁且可解释性强。
- **MoE 的合理引入**：用多个软门控专家建模异构散射模式（散射中心、阴影、杂波、分辨率效应）的混合，比单一特定分支更贴合实际问题；专家间无竞争（共享路径强制启用）的设计有效缓解少样本过拟合。
- **训练技巧完整**：路由域辅助损失 + 专家平衡损失 + 温度参数，形成一套防止路由崩溃、鼓励域感知路由的闭环。
- **实验严谨性**：修正基线 bug（AsyFOD†）、嵌套少样本划分、双向任务验证、多维度可视化分析（t-SNE、激活图、路由统计）相互印证，说服力强。

## 8. 不足与局限

- **任务覆盖单一**：仅使用**车辆单一类别**、三类数据集的 0.1 m 分辨率数据，未覆盖舰船、飞机等多类目标，也未验证中低分辨率场景，结论推广性有待检验。
- **1-shot 极限短板**：在 MiniSAR → FARAD-Ka 的 1-shot 设置下表现不及 AsyFOD†，暴露了方法在源域规模小且目标样本极稀缺时对目标分布估计敏感的问题，论文对此的解释偏定性，缺乏针对性改进。
- **专家数量经验化**：E 的选择（默认 4）基于经验调参，缺乏自适应机制；E=8 的性能回落说明路由不确定性在少样本下未被充分解决。
- **算力与效率信息缺失**：未报告训练/推理耗时、参数量、FLOPs 等效率指标，仅提及单卡 RTX 5090。
- **消融范围有限**：消融实验仅在前向两个任务上进行，未在更具挑战性的反向任务（MiniSAR → FARAD）上验证各组件贡献。
- **公平性潜在偏差**：所有方法均基于 AsyFOD 框架实现，对与框架结构差异较大的方法（如 SSDA-YOLO）可能不够友好；未见多次随机种子下的方差报告，少样本结果的稳定性存疑。
- **实际部署约束未讨论**：未分析路由域分类器移除后对推理简化的收益量化，也未讨论模型在新传感器上的快速部署流程。
